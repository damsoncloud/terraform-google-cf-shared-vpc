# Security Policy

## Supported versions

Only the latest release of this module receives security fixes. Fixes are published as a new release, so pin an exact version you have reviewed and upgrade promptly.

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions or pull requests.

Report them privately using [GitHub private vulnerability reporting](https://github.com/damsoncloud/terraform-google-cf-shared-vpc/security/advisories/new). Include:

- the affected version,
- a description of the vulnerability and its impact,
- steps to reproduce or a proof of concept, if available.

We will acknowledge the report, keep you informed about its progress and credit you in the published advisory, unless you prefer to stay anonymous.

## Scope

In scope are the source code in this repository and the module versions published on the Terraform Registry. Misconfigurations caused by the input values chosen by the module's
users are out of scope.
